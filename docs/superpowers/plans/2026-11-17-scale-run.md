# Scale Run (55 Cards) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the pilot `knowledge/` with the full knowledge base built from all 55 book cards. The result must pass every verifier gate, the per-file fidelity check, and Sebastián's review.

**Architecture:** The controller (the session running this plan) runs the stdlib scripts and dispatches agents with the prompts in `destilado/prompts/`. The flow: index the cards in 5 lots, have one agent cluster each lot, have one agent per kind merge the lots, bundle the source text, run one writer per knowledge file, then verify and run the per-file fidelity check. Each phase ends at a gate the controller runs before it moves on.

**Tech Stack:** Python 3 stdlib (`indice.py`, `verificar.py`, `fuentes.py`), Claude subagents, Markdown.

**Spec:** `docs/superpowers/specs/2026-11-13-story-engine-design.md` (Steps A–D, as updated 2026-11-17). Previous plan: `docs/superpowers/plans/2026-11-17-pre-scale-fixes.md`.

**Paths:**
- `$ROOT` = `/Users/sdavila/Desktop/Storytelling`
- `$D` = `$ROOT/destilado` (scripts, prompts, cards; local only)
- `RUN` = `$ROOT/destilado/escala` (every intermediate file of this run)
- `$K` = `$ROOT/story-engine/knowledge` (output)
- Ledger: `$ROOT/story-engine/.superpowers/sdd/2026-11-17-scale-run/progress.md` (untracked)

## Global Constraints

- Nothing is published: no push, no remote, no public repo.
- Never modify `fichas-gemini/` or `../md/`.
- IDs: `F001`, `S001`, `T001`, `Q001` (3 digits), `R01`. Final IDs are assigned only by the merge agents (`fusion.md`).
- Knowledge files: English, own words, no quotes, original examples, surname attribution, at most 5,000 tokens (words × 1.35).
- Rate limit: at most 3 Opus agents or 4 Sonnet agents at the same time. If an agent hits the 5-hour limit, log it in the ledger and resume it later with SendMessage. Do not redispatch it fresh.
- Models: clustering and merging (Tasks 3–4) use Opus. Writers and the fidelity check (Tasks 5–6) use Sonnet.
- Every prompt dispatch replaces the placeholders `RUN`, `N`, `K`, `TARGET` and `FILES` with concrete values. Paste the prompt file text into the agent prompt; do not just point to it.
- A gate that fails goes back to the agent that produced the file, with the exact verifier lines. Allow at most 3 fix rounds per agent, then stop and ask Sebastián.

**Interfaces:**

```python
    big_index = d / "index.md"

```

- [ ] **Step 2: Run and confirm failure.** Run `cd $D && python3 -I test_verificar.py`. Expected: `AttributeError: module 'verificar' has no attribute 'index'`.

- [ ] **Step 3: Implement.** In `verificar.py`, add after `ids()`:

```python
def index(files):
    rows = sorted(f"| {i} | {name.strip()} | {label(f)} |"
                  for f in files
                  for i, name in re.findall(r"^(?:## |- \*\*)([FST]\d{3}) · (.+?)(?:\*\*.*)?$", f.read_text(), re.M))
    return "\n".join(["| ID | Name | File |", "|---|---|---|"] + rows) + "\n"
```

In `budget()`, change the loop to `for f in files:` followed by `if f.name == "index.md": continue`. Add `"--index"` to `FLAGS`. In `main`, after `problems` is final and before printing, add:

```python
    if "--index" in opts and kfiles:
        Path(opts["--index"]).write_text(index([f for f in kfiles if f.name != "index.md"]))
```

Add `[--index FILE]` to the usage docstring.

- [ ] **Step 4: Run tests.** Run `python3 -I test_verificar.py && python3 -I test_indice.py && python3 -I test_fuentes.py`. Expected: `ok` three times.

### Task 2: Index the cards (Step A)

**Files:**
- Create (generated): `RUN/lotes/<1–5>/{indice.md,secciones.md,cartas.txt}`, `RUN/indice.md`, `RUN/secciones.md`, `RUN/dominios/*.md`, `RUN/preguntas.md`, `RUN/principios.md`

- [ ] **Step 1: Build 5 lots of 11 cards (alphabetical) and the full index.**

```bash
cd $D && python3 -I - <<'EOF'
import subprocess
from pathlib import Path
cards = sorted(Path("fichas-gemini").glob("*.md"))
assert len(cards) == 55, len(cards)
for n in range(5):
    lot = cards[n * 11:(n + 1) * 11]
    out = Path(f"escala/lotes/{n + 1}")
    subprocess.run(["python3", "-I", "indice.py", "--out", str(out), *map(str, lot)], check=True)
    (out / "cartas.txt").write_text("".join(c.name + "\n" for c in cards[n * 11:(n + 1) * 11]))
subprocess.run(["python3", "-I", "indice.py", "--out", "escala", *map(str, cards)], check=True)
EOF
```


Expected:

- `preguntas.md` is about 23,000 words and `principios.md` about 50,000.

If a lot is over 60,000 words, split it into two lots (`lotes/<N>a`, `lotes/<N>b`) and log the split in the ledger.
